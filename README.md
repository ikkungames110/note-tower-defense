# ノート上の戦い

本物のノートの上で、鉛筆の文字が戦うブラウザー向けタワーディフェンス。全4章・12ページ。インストール・アカウント不要です。

[ブラウザーで遊ぶ](https://ikkungames110.github.io/note-tower-defense/)

## 遊び方

- カードをクリック・タップ、または **1〜5** で「あ・い・う・え・お」を召喚。移動と攻撃は自動。
- **U**：「ためる力」で鉛筆の回復速度と容量を強化。**Q**：30秒チャージの消しゴムで敵全体を攻撃・押し戻し。
- **Space**：開始・停止・再開。ボタンにフォーカスしている場合はそのボタンを操作。
- 敵拠点と各ページのボスを倒すと勝利。自軍拠点のHPがゼロになると敗北。
- 次の波の敵編成を予告。倍速、文字図鑑、ガイド、再挑戦、ページ選択に対応。
- タブを離れる、またはダイアログを開くと停止。再開ボタンで戻ります。
- 音は初期ミュート。音符ボタンで有効にします。「動きを減らす」設定では大きな動きや文字の変形を省略します。

## 4章の構成

| 章 | ページ | 主な戦術 |
| --- | --- | --- |
| はじまりの余白 | 1〜3 | 5文字の役割、折り目、ボスの予兆と隙 |
| 折り目の向こう | 4〜6 | 手前と奥の折り目、前衛と後衛の射程差 |
| 書きかけのページ | 7〜9 | 完成前の敵への攻撃、Hの読点の除去 |
| さいごの見開き | 10〜12 | 既習の仕組みの組み合わせ、最終ボスZ、エンディング |

折り目では敵味方とも移動速度が半分。射程・攻撃速度・押し戻し距離は変わりません。書きかけの敵は4秒で完成し、それまでは移動・攻撃せず、完成前にも倒せます。Hが置く読点「、」はHP80、8秒で消える障害物（最大5個）。攻撃や消しゴムで除去でき、鉛筆の撃破報酬はありません。

## 育成とボス

各クリア後にランダム3択から1文字を強化。次の同じ母音の文字へ進化し、HP・攻撃力が初期値の8%分ずつ増加します。召喚コスト・クールダウンは変わりません。役割ごとに、強化1回あたり次の効果も加わります。

| 役割 | 追加効果 |
| --- | --- |
| あ：範囲攻撃 | 巻き込む範囲 +16 |
| い：速攻 | 出撃後4秒間の移動速度 +15% |
| う：遠距離 | 射程 +12 |
| え：押し戻し | 押し戻し距離 +8 |
| お：守り | 召喚後最初の被ダメージを15%軽減 |

育成は1章3ページで最大3回。同じ章の次ページへ引き継ぎ、次の章では初期編成へ戻ります。再挑戦はそのページ開始時の編成、ページ選択・再読み込みは初期編成。章末も最後の強化を選び、育った文字と能力を確認できます。

- **E**：1.2秒の構え → 0.28秒間隔の三連撃 → 2.5秒休止。一撃は通常攻撃力の60%。各打撃時点で射程を判定するため、押し戻すと空振りさせられます。
- **F**：1.4秒構え、射程155以内の前衛へ攻撃力の1.4倍の攻撃と85の押し戻し。その後2.2秒休止。射程外の後衛には届きません。
- **G**：接敵後2.4秒防御 → 1秒構え → 突き → 3秒休止。被ダメージは防御中0.35倍、構え中通常、休止中1.5倍。通常攻撃・範囲攻撃・消しゴムで共通。
- **Z**：最終ページのみ。三連撃で始まり、HP半分以下では休止を終えるたびに払い・守り・三連撃を繰り返します。予兆の途中で行動を変更しません。

通常敵のE・F・Gにはボス専用行動を付けません。拠点を早く削り切るとボスが登場し、ボス撃破前にクリアできない構成です。

## 保存・素材

localStorageに保存するのはクリアしたページ番号のみ。途中の戦闘・育成は保存しません。旧3ページ版・6ページ版の記録も利用でき、保存不可でもプレイできます。ゲームから外部API・フォント・音源・分析サービスへの通信は行いません。

教室とノートの背景、消しゴムは生成画像。制作記録は [public/assets/README.md](public/assets/README.md)。文字・城・読点は一画ずつのオリジナルパス。効果音はWeb Audioで合成し、粒子・破片・顔・手足は使いません。

採用した03調整版は開発サーバーの `/concepts/selected/index.html`、比較案は `/concepts/v2/index.html`。制作資料は本番ビルドから除外します。章の光は採用背景を基準に少しずつ変化します。

## 開発・検証

Node.js 22.12以上（CIは24）を使用します。

```bash
npm install
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser
npm run test:production
```

- `src/game.js`：DOMから独立した戦闘と育成。`src/stages.js`：全12ページの編成・地形・ボス・章構成。
- `src/render.js`：鉛筆の筆跡、書き上がり、静かな消失、投影影。影は事前描画して再利用。
- `src/main.js`：UI、入力、固定ステップ更新、保存、章末・エンディング。`src/audio.js`：紙・筆記・消しゴム風の合成音と短いチャイム。
- ロジックテストは全12ページの攻略、ギミック、育成効果、停止、ボス行動、勝敗を検証。
- Playwright/ChromiumでUIの全12ページ通し攻略・育成・章間リセット・エンディング・モバイル幅・動きを減らす設定・保存不可を検証。画像は `test-results/` に出力。スマートフォン表示はエミュレーションによる検証です。
- 本番テストはサブディレクトリ配信、画像、タッチ操作、旧セーブ、破損セーブ・保存禁止、外部通信なしを検証。

## 配信

`npm run build` で `dist/` にゲーム本体と必要な素材だけを出力します（約3MB）。相対パスなのでサブディレクトリに配信できます。

`.github/workflows/pages.yml` はmainへのpush時にロジック・ブラウザー・本番ビルドのテストを実行し、成功後にGitHub Pagesへデプロイします。PRでは検証のみを実行します。リポジトリのPages設定は **GitHub Actions** を使用します。
