# もじもじ大作戦

## ビジュアル案の比較

最新の03調整版は `/concepts/selected/index.html`。選択した第2回03を基準に、周囲の破片を除き、普通の鉛筆書きに整えています。修正前との切り替え比較もできます。

開発サーバーの `/concepts/v2/index.html` で、低い視点のノート上に、薄い鉛筆の文字が垂直に立つ10案を比較できます。画像の拡大、5段階評価、メモの自動保存、評価のコピー・テキスト保存に対応します。`public/concepts/v2/index.html` を直接開いても閲覧できます。画像と生成プロンプトは同じディレクトリに保存しています。

ゲーム画面は03調整版を元に作り直しています。低い視点の教室・ノート背景に、一画ずつ描いた鉛筆の文字と紙面に投影した影を重ねています。UIは温かい紙色の小さな操作帯にまとめ、説明は「あそびかた」「文字のこと」に収めています。

背景は `public/assets/classroom-notebook.png`。内蔵 image_gen で調整版から文字と影を除去した素材で、プロンプトは `public/assets/README.md` に保存しています。文字の筆跡は `src/letters.js` で定義し、CanvasとUIで共有します。

## 起動と操作

ノートの上で「あいうえお」と「ABCDE」が戦うブラウザー向けタワーディフェンス。文字の形を生かした攻撃で、右の敵拠点を攻略します。

```bash
npm install
npm run dev
```

Node.js 20.19以上、または22.12以上が必要です。

- カードをクリック・タップ、または **1〜5** で召喚。
- **U**：「ためる力」でインク強化。**Q**：30秒チャージの消しゴム。
- **Space**：開始・停止・再開。ボタンにフォーカスしている場合はそのボタンを操作。
- 3ステージ、倍速、文字図鑑、効果音（初期ミュート）、クリア記録の自動保存。
- タブを離れたり図鑑を開いたりすると一時停止します。再開ボタンで戻ります。

```bash
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser
```

ブラウザーテストは独自に開発サーバーを起動します。実装と制作の方針は [AGENTS.md](AGENTS.md) を参照してください。ゲーム本体は外部画像・フォント・音源・APIに依存しません。音はWeb Audioによる短い効果音です。
