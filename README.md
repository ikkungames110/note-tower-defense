最新の03調整版は `/concepts/selected/index.html`。選択した第2回03を基準に、周囲の破片を除き、普通の鉛筆書きに整えています。修正前との切り替え比較もできます。

ゲーム画面は03調整版を元に作り直しています。低い視点の教室・ノート背景に、一画ずつ描いた鉛筆の文字と紙面に投影した影を重ねています。UIは温かい紙色の小さな操作帯にまとめ、説明は「あそびかた」「文字のこと」に収めています。

背景は `public/assets/classroom-notebook.png`。内蔵 image_gen で調整版から文字と影を除去した素材で、プロンプトは `public/assets/README.md` に保存しています。文字の筆跡は `src/letters.js` で定義し、CanvasとUIで共有します。

## 起動と操作

ノートの上で「あいうえお」と「ABCDE」が戦うブラウザー向けタワーディフェンス。文字の形を生かした攻撃で、右の敵拠点を攻略します。

```bash
npm install
npm run dev
```

Node.js 22.12以上が必要です（開発依存のElectronを含む）。

- カードをクリック・タップ、または **1〜5** で召喚。
- **U**：「ためる力」で鉛筆強化。**Q**：30秒チャージの消しゴム。
- **Space**：開始・停止・再開。ボタンにフォーカスしている場合はそのボタンを操作。
- 2章・6ステージの体験版、倍速、文字図鑑、効果音（初期ミュート）、クリア記録の自動保存。
- タブを離れたり図鑑を開いたりすると一時停止します。再開ボタンで戻ります。

```bash
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser
```

ブラウザーテストは独自に開発サーバーを起動します。実装と制作の方針は [AGENTS.md](AGENTS.md) を参照してください。ゲーム本体は外部画像・フォント・音源・APIに依存しません。音はWeb Audioによる短い効果音です。

## 文字の強化とボス

各ページのクリア後、5枠それぞれの次の行の文字からランダムに3択を表示します（例：あきすえこ → か・し・つ・け・そ）。1枠を選ぶとHPと攻撃力が初期値の8%分増え、役割・召喚コスト・待機時間は維持。1章3ページで最大3回、24%までの強化です。章内の「次のページ」で引き継ぎ、「次の章へ」では初期編成に戻ります。再挑戦はそのページ開始時の編成に戻ります。ページ選択と再読み込みでは編成をリセットし、クリア記録だけ保存します。最終ページでも選択でき、育った5文字を確認できます。

通常敵は各章の1ページ目がA〜D、2ページ目がA〜E、3ページ目がA〜F。各ページに一体だけ、大きなE・F・Gが登場します。勝利には敵拠点のHPゼロとボス撃破が必要です。最終ウェーブ前に拠点を削り切った場合は、その時点でボスが登場します。

拠点は文字と同じ鉛筆の線による旗付きの城の落書きで、ノートに垂直に立つ影を付けています。消しゴムは `public/assets/eraser.png` を使用し、2.4秒かけて往復しながら紙面をこすります。ダメージは発動時に適用し、倒れた文字の筆跡をこすった側から消します。動きを減らす設定では往復と画面横断を止めます。生成プロンプトは `public/assets/README.md` を参照してください。

## ページごとの戦術（6ページ体験版）

- `src/stages.js` に、各ウェーブの開始秒・敵の並び・出現間隔・ボス・折り目を定義。画面の操作帯で次の波までの秒数と敵の種類を確認できます。
- 1・4ページ目のボスEは、1.2秒の構え → 0.28秒間隔の三連撃 → 2.5秒の休止。各打撃時点で射程を判定するため、消しゴムで押し戻すと空振りさせられます。三連撃は一撃につき通常攻撃力の60%。通常敵のEは従来の行動です。
- 2・3ページ目は中央の折り目（論理座標X=550〜650）で、敵味方とも移動速度が半分になります。攻撃速度・射程・押し戻し距離は変わりません。
- 味方は一画ごとに、輪の回転・二本の交互打ち・点の跳ね・払い・守りの踏ん張りを表現。進化後も役割に応じた動きを保ちます。動きを減らす設定では文字の変形を止め、ボスの状態は文字でも表示します。
- 2・5ページ目のボスFは1.4秒の構えから、射程155以内の前衛へ攻撃力の1.4倍のダメージと85の押し戻し。その後2.2秒休止。射程外の後衛には届きません。
- 3・6ページ目のボスGは接敵後2.4秒守り、1秒構えて攻撃力の1.4倍で突き、3秒休止。防御中は被ダメージ65%減、構え中は通常、休止中は1.5倍。通常攻撃・範囲攻撃・消しゴムで共通です。
- 第2章では4ページ目の折り目を手前（X=420〜520）、6ページ目を奥（X=670〜770）に配置。5ページ目には折り目がなく、前衛と後衛の射程差を生かします。
- 章末は最後の強化を選び、育った5文字を表示。章ごとに初期編成から攻略でき、章末の再挑戦はそのページ開始時の編成に戻ります。ページ移動には短い切り替え演出を付け、動きを減らす設定では省略します。
- 旧3ページ版のクリア記録はそのまま有効。3ページ目のクリア記録があれば4ページ目を選べます。保存するのはクリア記録のみです。
- 12ページへの拡張、書き足される敵などの新ギミック、追加の育成効果は次段階です。

検証は `npm test`、`npm run build`、`npm run test:browser`。ブラウザーテストは従来の通し攻略に加え、全6ページ攻略、章内育成と章間リセット、旧記録互換、E・F・Gの予告と休止、折り目、攻撃中の文字、動きを減らす設定、320px・390pxの表示を確認し、`test-results/` に画像を保存します。
